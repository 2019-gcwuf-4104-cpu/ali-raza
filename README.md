# 💕 A Special Message for aalishali

A beautiful, animated website to express love and apology. Created with HTML, CSS, and JavaScript.

## 🔐 Features

- **Password Protected** - Secured with date of birth (06/02/2008)
- **Stunning Animations** - Letter bounce, floating hearts, particle effects
- **Emotional Messages** - Personalized apology from Ali to aalishali
- **Interactive Elements** - Button with confetti and particle effects
- **Fully Responsive** - Works beautifully on all devices
- **Modern Design** - Beautiful gradients and smooth transitions

## 🚀 How to Use

1. Visit the website
2. Enter the date of birth: 06/02/2008
3. Click "Unlock" to view the special message
4. Enjoy the beautiful animations!

## 📝 Files

- `index.html` - Main HTML structure
- `style.css` - All styling and animations
- `script.js` - Interactivity and effects
- `README.md` - This file

## 🎨 Customization

You can customize:
- Messages in the message boxes
- Passcode date (change in script.js)
- Colors and gradients (in style.css)
- Names (find and replace "aalishali" and "Ali")
